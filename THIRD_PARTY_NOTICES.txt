THIRD-PARTY NOTICES
===================

ykkz000's Soviet Union (Rework) no longer statically links any third-party
software. The Soviet Union consumer plugin links only the shared ABI headers and
the import libraries of the API plugins shipped by ykkz000's DLL Plugin API.

The loader DLL that hosts the plugins statically links third-party software;
its notices are shipped with the ykkz000's DLL Plugin Loader mod (see that mod's
THIRD_PARTY_NOTICES.txt).
